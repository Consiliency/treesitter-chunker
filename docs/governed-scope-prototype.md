# Governed source snapshot prototype

`tools/governed_scope.py` is a standalone stdlib tooling driver, not a change to the
published Boundary IR API. Invoke the verified script with `python -I -S`, a closed
request JSON and a new output directory outside the source tree. Both consumers
supply an independently expected driver SHA-256 and policy digest. No parser runs
inside the driver; it stages only selected regular files for the consumer's parser.

The project supplies an ownership assertion and explicit external/unknown rules.
Directory names alone cannot prove ownership. Nested Git roots and submodules are
opaque regardless of common ownership. Symlinks never authorize reading their
targets. No excluded descendant is hashed as source evidence. The external
reference digest records boundary metadata only.

Successful output contains `stage/`, `selection.json`, `selection-receipt.json`
and operational locators. Schema/root/path/metadata failures before classification
are diagnostics only. Classification and copy refusals retain blocked receipts;
partial stages are never parsed. Existing output is never overwritten. Canonical
scope JSON uses the specified Python JSON preimage, not the Spec canon profile.

This is a quiescent-snapshot contract, not protection against a hostile concurrent
filesystem writer. Unsupported no-follow platforms refuse. Legacy extraction
remains unchanged and is not claimed to enforce this scope. Run the dedicated
conformance test from the locked environment; Linux no-read tests trace the actual
child with strace and require that tool rather than crediting an unobserved run.

Consumer test transports are generated byte copies of this script with an explicit
SHA-256 binding. They are test data only: production callers never discover or
silently fall back to them. Refresh from this owner source after a reviewed change.
